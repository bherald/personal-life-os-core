## Upgrade and support

Back up original media, databases and configuration. Inspect included migrations
against your schema and test an upgrade on a disposable copy first. The public
baseline supplies generic configuration, not the maintainer's model catalog.

Core and optional research/model/media services have separate requirements.
Controller experiments remain unqualified for public hardware. No private
photos, biometric vectors, genealogy records, routes or credentials are shipped.
Use synthetic/permitted data in bugs and follow [SECURITY.md](../../SECURITY.md)
for private security reporting.
