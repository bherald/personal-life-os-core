# Framework upgrade boundaries

Research, quality evaluation and batch text indexing preserve complete inputs.
Configured byte, memory, token and controller limits hold work before dispatch
instead of substituting a prefix. Quality uncertainty propagates through the
existing admission boundary; old partial vectors are never relabeled or replayed.

Quarantined files are excluded from EXIF selection and publication. Automatic
image tagging requires an explicit `files.ai_auto_tag_vision_model_selection`
table binding, registered vision eligibility and the existing native runtime and
resource contract. The new selector defaults empty. Preserve file bytes and
operator-owned identity decisions; releasing quarantine is a separate decision.

Retrieval compares embedding model, artifact revision and dimension before
ranking. Equal complete content-addressed artifact revisions can match across
routing hosts. Missing legacy identity follows the registered policy; lexical
results remain available. Deploy matching source and registration migrations.

Scheduled recovery distinguishes physical terminality from domain completion.
Existing proof-bound UNKNOWN closure retains original receipts and forbids replay.
Separate fresh-work checkpoints cover empty current capture, retained registered
child admission, durable discovery queues and registered native task bindings.
These do not release unproven custody or mark historical work successful. Manager
lanes report only an exact known refusal before child dispatch as blocked; wrapped,
unknown and post-dispatch failures continue to propagate their admission holds.

The bounded upstream preparation worker is registered disabled, including its
admission and worker tools. Enabling it requires separately qualified exact
framework transport, private journal, caller, assignment, source, budgets,
workspace, model route, supervisor custody and rollback artifacts. Selector IDs
are not authority. Existing launch intent and uncertain outcomes block automatic
replay. Prepared output reaches operator review; publication remains a separate
explicit approval. This update supplies no host, journal, grant or activation.

The architecture-reference discovery aliases are retired. The migration removes
only their registered aliases and matching records; it preserves independently
configured connectors. Container removal and volume retention remain separate
operator operations.

Use the normal installation upgrade procedure, refresh the pinned CLI registry
when tool contracts change and verify the selected role with successful end-to-end
completion. Rollback restores matching source and policy preimages, preserving
file bytes, vectors, operator overrides, UNKNOWN receipts and descendant custody.
Do not clear evidence or reset schedules to force admission. Existing public
release checks remain required; local tests do not substitute for hosted CI.

Generic scheduled-agent execution retains the custody-owned scheduled run and
process identity in agent options and durable session metadata. Invalid or foreign
ownership holds before dispatch. This provides future lineage; it does not bind
old unproved sessions or authorize replay of historical work.

Managed knowledge-graph batches run serially in groups of at most three. The
existing native transport admits and closes each exact table-bound request; the
coordinator reports progress and holds no outer model permit. Admission or budget
stops preserve original input and stop later documents. Input over budget is
refused instead of truncated. Managers re-read the selected scheduled definition
and wait when it is disabled, including before forced scheduler handoff.

Media RAG indexing accepts both existing-document boolean update receipts and
new-document object insertion receipts through the current-source publication
guard. Completion stamps follow verified guarded publication. Failures retain
closed reason codes, exception types and whitelisted SQLSTATE/driver primitives;
private messages, source text, bindings and traces stay redacted. Restore source
for rollback without clearing stamps, document bytes or uncertain receipts.

Exact alternate embedding roles remain table-bound rather than being rewritten
to the global embedding role. Installed capability, context and native admission
still apply. Existing vector indexes and model/revision/dimension fingerprints
are preserved; an alternate dimension never promotes itself into an old space.

Dedicated CPU reranking uses the existing Qwen final-token binary scorer with
complete query/document pairs and refusal before any oversized pair is scored.
Explicit `rag:rerank --cross-encoder` preserves base64 inputs and requires the
registered model, role, revision, native receipt and resource contract. Actual
request bytes, complete finite scores and table-bound loopback HTTP Host are
verified through native controller custody. Unknown outcomes remain held without
replay; normal lexical, AI and embedding defaults are preserved.

The public registration creates a disabled empty selection. Operators own model
catalogs, pinned artifacts, credentials, native tasks and capacity qualification;
this source includes no private host adoption data or automatic activation.
The portable Windows lifecycle requires explicit `-ManifestPath` and trusted
`-ExpectedHostId`, with exact native receipt/process/listener/runtime guards.
Supply matching table/native projections, preserve the desktop reserve and
uncertain custody, and retain model license notices. The existing evaluation
launcher remains separate from the controller-owned production route.

Native lifecycle receipt identities come from the explicitly verified host
binding. Technical fencing additionally requires the explicit qualified K3
custody manifest; an absent binding holds the action. Native source packages do
not include host manifests, tasks, credentials or activation scripts. Review the
operator-owned controller API invocation and source pins together when adopting
the portable lifecycle implementation.

Public host-adoption migrations now require operator-owned packets explicitly.
With no packet present or declared, the 17 legacy packet-reading migrations skip
all host adoption; they do not select a host, activate a model, or change existing
bindings. A partially present required packet set refuses before writes. An
operator can require exact repository-relative paths through the existing
`ai.model_host_controller_policy` table value, controller/provider/profile binding
metadata, or the config fallback, using `operator_adoption_packet_paths`. Missing
declared packets fail closed. Existing admission, identity, custody, history and
rollback guards still run unchanged when all required packets are supplied.
Unrelated active controllers do not imply adoption of every historical candidate.
Host packets and native setup remain operator-owned and are omitted from export.
Focused isolated tests exercise all 17 migrations in production mode without
packets, partial packet refusal, declared binding refusal, and complete-set
applicability. This verifies that boundary, rather than a complete fresh install.

Colibri native task identity now accepts only an explicit table-owned
`task_logon_type` of Interactive or S4U. Absence retains strict legacy Interactive.
Registration makes that prior guard explicit while preserving existing choices
and creating no host policy on an unconfigured installation. Nonlegacy S4U is
bound into matching PHP/PowerShell capacity hashes. Exact principal, executable,
arguments, working directory, Highest run level and zero-trigger guards remain.
Portable source and synthetic controls are included; operator task repair,
credentials, native/table projection and runtime activation remain outside export.
Retained verification: nine PHP controls/18 assertions, fifteen native synthetic
task identity controls and two cross-language capacity hash comparisons passed.

Cold reranker readiness can fail before generic activation records ownership.
The existing adapter now performs qualified cleanup and emits a typed failure
only after exact task/runtime identity and empty process/listener readback.
Busy, foreign, interrupted or uncertain cleanup remains UNKNOWN; timeout alone
authorizes neither termination nor replay. The activation receipt records verified
failure without a lease and returns it unchanged for the original request.

Activation HTTP budgets include table-owned startup, optional verification and
request overhead with the existing mutation floor. A disabled authenticated
reranker cannot answer its health endpoint: only registered adapter identity,
exact runtime files, disabled task and zero owned process/listener permit its
explicit null busy observation at the technical fence. Live or other adapters
retain strict idle evidence. Existing owner, lease, generation, K3 custody and
operator-authority guards remain. Deploy matching lifecycle/helper pins and
operator-owned projections; rollback restores matching source/native policy
preimages without clearing journals or relabeling UNKNOWN work.

Public verification adds thirteen model-free PHP controls/96 assertions and
portable native mock fixtures. Existing scoped proofs are retained; no model
benchmark or complete-suite/fresh-install claim is implied.
