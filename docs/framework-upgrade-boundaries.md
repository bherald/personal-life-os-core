# Framework upgrade boundaries

Research, quality evaluation and batch text indexing preserve complete inputs.
Configured byte, memory, token and controller limits hold work before dispatch
instead of substituting a prefix. Quality uncertainty propagates through the
existing admission boundary; old partial vectors are never relabeled or replayed.

Quarantined files are excluded from EXIF selection and publication. Automatic
image tagging requires an explicit `files.ai_auto_tag_vision_model_selection`
table binding, registered vision eligibility and the existing native runtime and
resource contract. The new selector defaults empty. Preserve file bytes and
operator-owned identity decisions; releasing quarantine is a separate decision.

Retrieval compares embedding model, artifact revision and dimension before
ranking. Equal complete content-addressed artifact revisions can match across
routing hosts. Missing legacy identity follows the registered policy; lexical
results remain available. Deploy matching source and registration migrations.

Scheduled recovery distinguishes physical terminality from domain completion.
Existing proof-bound UNKNOWN closure retains original receipts and forbids replay.
Separate fresh-work checkpoints cover empty current capture, retained registered
child admission, durable discovery queues and registered native task bindings.
These do not release unproven custody or mark historical work successful. Manager
lanes report only an exact known refusal before child dispatch as blocked; wrapped,
unknown and post-dispatch failures continue to propagate their admission holds.

The bounded upstream preparation worker is registered disabled, including its
admission and worker tools. Enabling it requires separately qualified exact
framework transport, private journal, caller, assignment, source, budgets,
workspace, model route, supervisor custody and rollback artifacts. Selector IDs
are not authority. Existing launch intent and uncertain outcomes block automatic
replay. Prepared output reaches operator review; publication remains a separate
explicit approval. This update supplies no host, journal, grant or activation.

The architecture-reference discovery aliases are retired. The migration removes
only their registered aliases and matching records; it preserves independently
configured connectors. Container removal and volume retention remain separate
operator operations.

Use the normal installation upgrade procedure, refresh the pinned CLI registry
when tool contracts change and verify the selected role with successful end-to-end
completion. Rollback restores matching source and policy preimages, preserving
file bytes, vectors, operator overrides, UNKNOWN receipts and descendant custody.
Do not clear evidence or reset schedules to force admission. Existing public
release checks remain required; local tests do not substitute for hosted CI.

Generic scheduled-agent execution retains the custody-owned scheduled run and
process identity in agent options and durable session metadata. Invalid or foreign
ownership holds before dispatch. This provides future lineage; it does not bind
old unproved sessions or authorize replay of historical work.

Managed knowledge-graph batches run serially in groups of at most three. The
existing native transport admits and closes each exact table-bound request; the
coordinator reports progress and holds no outer model permit. Admission or budget
stops preserve original input and stop later documents. Input over budget is
refused instead of truncated. Managers re-read the selected scheduled definition
and wait when it is disabled, including before forced scheduler handoff.
