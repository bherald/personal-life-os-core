# Public-core direction

Current work prepares a reviewed v2.1 candidate. It is not a release-date,
hosted-service or private-operator-parity commitment.

- Explain research with inspectable sources and visible limits.
- Keep Docker-first installation, upgrade checks and setup doctor useful.
- Provide synthetic/licensed examples and focused behavior tests.
- Preserve privacy, provenance, notices and operator approval.
- Separate portable photo context from private embedding/identity evidence.
- Qualify optional model/controller/media paths before claiming support.

Private data, credentials, weights and deployment topology remain excluded.
